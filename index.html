// how it works

Three steps, then it's yours.

No reading documentation. No editing config files. Just answer a few questions.

01

Paste one command

Open a terminal on your home server and paste the install command. That's it — homelab-starter checks that Docker is installed and offers to install it for you if not.

~30 seconds
02

Pick your apps

A checklist appears. Scroll through 28 apps with short descriptions. Space bar to check, Enter to confirm. No configuration knowledge needed — sensible defaults are set for everything.

~2 minutes
03

Bookmark your dashboard

homelab-starter starts everything and prints the URL for each app. If you installed Homepage, it opens your dashboard link and suggests you bookmark it. Done.

~5 minutes total

// why homelab-starter

Built for everyone, not just sysadmins.

No Cloudflare account required. No license tiers. No breaking upgrades.

⚡

Works on any DNS provider

Namecheap, Route53, Porkbun — no Cloudflare lock-in. Point your domain wherever it already lives.

🔑

Passwords generated for you

Every app that needs a secret key or database password gets a cryptographically secure one. No copy-pasting required.

🧩

Your choice of reverse proxy

Caddy is offered but optional. Skip it and apps are still accessible by IP. No tool-wide architecture lock-in.

💚

Fully open source, always free

No Basic / Plus / Pro tiers. No membership wall. Every feature in the repo, forever.
